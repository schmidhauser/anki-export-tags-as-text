### Keyboard Shortcuts

`shortcut_copy` specifies the keyboard shortcut for **Copy Tags as Text**.

`shortcut_save` specifies the keyboard shortcut for **Save Tags as Text…**

To disable a shortcut, set it to the empty string (`""`).

No restart is required.

On macOS, Qt interprets `Meta` as Control (`⌃`), `Ctrl` as Command (`⌘`), `Alt` as Option (`⌥`), and `Shift` as `⇧`. The default shortcuts are therefore `⌃⇧⌘T` and `⌃⇧⌘E`.
